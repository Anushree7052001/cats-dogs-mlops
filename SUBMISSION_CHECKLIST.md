# Submission checklist

M1: Git, DVC dataset, 224x224 RGB, 80/10/10 split, augmentation, CNN, saved model, MLflow, confusion matrix/curves.
M2: FastAPI health/predict, requirements, Dockerfile, local prediction.
M3: pytest preprocessing + inference, GitHub Actions, Docker build/publish.
M4: Docker Compose, registry image, deployment update, smoke test.
M5: request/latency logs, simulated/real requests and true labels, performance.
Final: ZIP source/configuration/model artifacts + recording under 5 minutes.

Do not claim a step is completed until it has actually been run and verified.
